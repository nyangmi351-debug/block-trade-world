블록 무역 월드 - 학생들이 동시에 접속하게 만드는 방법

★ 반 코드 (여러 반이 함께 쓰기)
  - 선생님마다 처음 화면에서 "새 반 만들기" → 반 이름 + 선생님 PIN(4자리)을 정해요.
  - 겹치지 않는 반 코드(예: K7Q2M)가 생겨요. 게임·채팅·결과가 반마다 완전히 따로예요.
  - 학생은 "주소?c=반코드" 링크로 들어오거나, 처음 화면에서 반 코드를 입력해요.
  - 선생님 관리자 화면에 우리 반 코드와 학생용 주소가 늘 보여요.
  - 무료 요금제는 동시에 100명까지라서, 한꺼번에 3반(약 80명)까지 함께 할 수 있어요.

(처음 한 번만 하면 돼요. 약 10분)
==================================================

이 폴더에 들어 있는 파일
  - index.html          게임 본체 (건드리지 않아요)
  - firebase-config.js  선생님이 Firebase 주소를 붙여 넣는 파일
  - README.txt  지금 보고 있는 설명서

※ Firebase(구글의 무료 실시간 서버)가 학생들의 위치, 채팅, 무역을
  서로 전달해 줘요. 구글 계정만 있으면 무료로 쓸 수 있어요.


[1단계] Firebase 프로젝트 만들기
  1) https://console.firebase.google.com 에 구글 계정으로 들어가요.
  2) "프로젝트 만들기(또는 프로젝트 추가)"를 눌러요.
  3) 이름을 적어요. 예: block-trade-world
  4) "Google 애널리틱스"는 꺼도 돼요. → "프로젝트 만들기"


[2단계] 실시간 데이터베이스 만들기  ★반드시 3·4단계보다 먼저★
  1) 왼쪽 메뉴에서 "빌드(Build)" → "Realtime Database"를 눌러요.
  2) "데이터베이스 만들기"를 눌러요.
  3) 위치는 "미국(us-central1)"을 그대로 두고 "다음".
  4) "잠금 모드로 시작"을 고르고 "사용 설정".


[3단계] 규칙(Rules) 바꾸기
  1) Realtime Database 화면 위쪽의 "규칙(Rules)" 탭을 눌러요.
  2) 안에 있는 글을 모두 지우고 아래 내용을 그대로 붙여 넣어요.

{
  "rules": {
    "btw": {
      ".read": true,
      "c": {
        "$code": {
          ".write": "root.child('btw/classes/' + $code).exists()"
        }
      },
      "classes": {
        "$code": {
          ".write": "!data.exists()",
          ".validate": "newData.hasChildren(['name', 'pin', 'at'])"
        }
      }
    }
  }
}

  3) "게시(Publish)"를 눌러요.
  ※ "공개되어 있다"는 경고가 나올 수 있어요. 게임 위치·채팅만 오가는
    곳이라 괜찮지만, 학생 이름은 실명 대신 이름(성 빼고)이나 별명을 쓰세요.


[4단계] 웹 앱 등록하고 설정 복사하기
  1) 왼쪽 위 "프로젝트 개요" 옆 톱니바퀴 → "프로젝트 설정".
  2) 아래쪽 "내 앱"에서 웹 아이콘 </> 을 눌러요.
  3) 앱 닉네임을 적고(예: game) "앱 등록".
     (Firebase 호스팅 체크는 하지 않아요.)
  4) 화면에 나오는 코드 중에서 아래처럼 생긴 부분만 복사해요.

     const firebaseConfig = {
       apiKey: "AIza.....",
       authDomain: "....firebaseapp.com",
       databaseURL: "https://....firebaseio.com",
       projectId: "....",
       ...
     };

     ※ import ... 로 시작하는 줄은 복사하지 않아요.
     ※ 나중에 다시 보려면: 프로젝트 설정 → 내 앱 → "SDK 설정 및 구성" → "구성(Config)"


[5단계] firebase-config.js 에 붙여 넣기
  1) firebase-config.js 를 마우스 오른쪽 → "연결 프로그램" → "메모장"으로 열어요.
  2) const firebaseConfig = { ... }; 부분을 지우고, 4단계에서 복사한 내용을 붙여 넣어요.
     (const firebaseConfig 가 두 번 들어가면 안 돼요!)
  3) 저장해요. (Ctrl + S)


[6단계] Netlify에 올리기
  1) https://app.netlify.com/drop 에 들어가요. (로그인한 상태)
  2) 이 폴더 전체를 화면에 끌어다 놓아요.
  3) 잠시 뒤 생기는 주소(○○○.netlify.app)를 학생들에게 알려 줘요.
  ※ 이미 올린 사이트를 고칠 때는: Netlify에서 그 사이트 → "Deploys" 탭 →
    아래쪽 끌어다 놓는 칸에 폴더를 다시 놓으면 주소가 그대로 유지돼요.


[7단계] 확인하기
  - 주소를 열었을 때 왼쪽 위에 "🟢 실시간 서버에 연결됐어요"가 나오면 성공!
  - "🔴 ... 규칙(Rules)" → 3단계를 다시 확인해요.
  - "🔴 ... 연결하지 못했어요" → 5단계의 붙여 넣기를 다시 확인해요.
  - "혼자 연습하기만 할 수 있어요" 문구가 보이면 → firebase-config.js 가 아직 기본값이거나
    글자가 잘못 들어간 거예요.


수업 진행 순서
  1) 선생님: 주소 열기 → 반 코드 입력(처음엔 "새 반 만들기") → "선생님 관리자" → 우리 반 PIN
     → 학생 수 입력 → "게임 시작"
  2) 학생: 각자 기기에서 "주소?c=반코드" 열기 → "학생으로 입장" → 번호와 이름 입력
  3) 끝나면 선생님 화면에서 "게임 끝" → 결과 저장


무료 사용량 (Firebase 무료 요금제 Spark)
  - 동시에 100명까지 접속할 수 있어요. (한 반 26명 + 선생님 = 충분)
  - 한 달에 받을 수 있는 데이터는 10GB예요.
    26명이 40분 동안 계속 돌아다니면 대략 1GB 안팎이 쓰일 것으로 예상해요.
    (Firebase 콘솔 → Realtime Database → "사용량" 탭에서 확인할 수 있어요.)
  - 무료 한도를 넘으면 요금이 나가는 게 아니라 그달 동안 멈춰요.
    (결제 카드를 등록하지 않았을 때)
